# Learnify Digital — landing

Sitio de [learnifydigital.com](https://learnifydigital.com), publicado con Netlify.

## Archivos

- `index.html`: la landing (inicio, sobre nosotros, servicios, contacto)
- `privacidad.html`, `terminos.html`, `reembolsos.html`: páginas legales
- `gracias.html`: página que se muestra después de enviar el formulario
- `assets/legal.css`: estilos de las páginas legales
- `favicon.svg`: ícono de la pestaña

## Cómo se publica

Cada cambio que se sube a la rama `main` se publica solo en Netlify en 1 o 2 minutos.

## Formulario

El formulario de contacto usa Netlify Forms. Los mensajes aparecen en Netlify, en la sección **Forms**, y se pueden reenviar por email desde **Forms → Form notifications**.

## Links viejos

Los links del sitio anterior (`#privacy`, `#terminos`, `#reembolso`, `#about`, `#work`, `#contact`) redirigen a las secciones o páginas nuevas.
